User Guide

1. Input Format

Provide informational text with clear facts, definitions, and concepts. Both direct text entry and standard searchable PDF uploads are supported.

2. Targeted Questions (Highlight Tool)

To produce a question on a specific term, select the text in the input box and click "Highlight Selection as Answer".

3. Multiple Choice Practice

In Interactive Quiz Mode, select an option for each question and click "Submit Quiz & Evaluate" for automatic scoring.

4. Export Options

Use Export PDF to download a clean, printable worksheet with an answer key, or Copy All for Markdown/Word.
